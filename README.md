
# Sarka app

## Reporting Issues
If you encounter a bug or have a suggestion for a new feature for the Sarka app, please use the Issues tab.

**Bugs**: Please include steps to reproduce the issue, your device model, and the app version.

**Feature Requests**: Clearly describe the proposed functionality and how it would improve your experience.

## Raportointi
Jos havaitset virheen tai sinulla on ehdotus Sarkan uudeksi ominaisuudeksi, käytä Issues-välilehteä.

**Bugit**: Ilmoita askeleet virheen toistamiseksi, käyttämäsi laitemalli sekä sovelluksen versio.

**Ominaisuuspyynnöt**: Kuvaile ehdotettu toiminnallisuus selkeästi ja kerro, miten se parantaisi käyttökokemustasi.

## Rapportering
Om du hittar ett fel eller har förslag på en ny funktion i Sarka-appen, vänligen använd fliken Issues.

**Buggar**: Ange stegen för att återskapa felet, din enhetsmodell och appversionen.

**Funktionsförfrågningar**: Beskriv den föreslagna funktionen tydligt och hur den skulle förbättra din användarupplevelse.
